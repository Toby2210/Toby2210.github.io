### [Image Merger Tool (Table Mode)](Image_Merger_Tool_Table_Mode/index.html)
Combine multiple images into a single table layout with customizable options.

#### 📖 How to Use

1. **Configure Table Settings**:
   - Set the number of **Table rows** and **Table columns** to define your grid layout
   - Adjust **Row spacing** and **Column spacing** (in pixels) for custom gaps between cells

2. **Create Table**:
   - Click the **"Create Table"** button to generate the grid

3. **Upload Images** (two methods):
   
   **Method A: Upload Individual Images**
   - Click **"Choose File"** to select one or multiple image files
   - Drag and drop images from the upload area onto table cells
   
   **Method B: Upload ZIP File** (Quick Upload)
   - Prepare a ZIP file containing your images
   - Click **"Choose File"** and select your ZIP file
   - The tool will automatically extract all images from the ZIP
   - Images are sorted alphabetically by filename

4. **Arrange Images**:
   - Drag images from the upload area onto specific table cells
   - Or use **"Auto-fill (ascending)"** to fill cells in order (1, 2, 3...)
   - Or use **"Auto-fill (descending)"** to fill cells in reverse order

5. **Merge Images**:
   - Click **"Merge Table Images"** to combine all images in the table
   - The merged image will be displayed as a canvas

6. **Download**:
   - Click **"Download Merged Image"** to save your result

#### 💡 Tips
- All operations are performed locally in your browser - your images are never uploaded to any server
- You can clear all images and start over using the **"Clear table"** button
- The tool supports common image formats: JPG, PNG, GIF, BMP, WebP
