圖片合併工具

注意：這個工具不會存起上傳的內容，所有操作均在本地完成，確保您的隱私安全。
Note: This tool does not store uploaded content. All operations are performed locally to ensure your privacy.

📖 使用教學 | How to Use

步驟 1：設定表格

首先設定您要使用的表格配置：

  • 表格行數 (Table rows)：設定表格的垂直行數
  • 表格列數 (Table columns)：設定表格的水平列數
  • 行間距 (Row spacing)：設定行與行之間的間距（像素）
  • 列間距 (Column spacing)：設定列與列之間的間距（像素）

設定完成後，點擊 "建立表格" (Create Table) 按鈕生成表格。

步驟 2：上傳圖片

您可以使用以下兩種方式上傳圖片：

方法 A：上傳單張或多張圖片

  • 點擊 "Choose File" 按鈕
  • 選擇一張或多張圖片文件（支援 JPG, PNG, GIF, BMP, WebP）
  • 選擇的圖片會顯示在下方預覽區

方法 B：上傳 ZIP 檔案（快速上傳）

  • 準備一個包含圖片的 ZIP 檔案
  • 點擊 "Choose File" 按鈕
  • 選擇您的 ZIP 檔案
  • 工具會自動解壓並提取所有圖片
  • 圖片會按文件名稱自動排序

步驟 3：將圖片放入表格

有幾種方法可以將圖片放置到表格中：

  • 拖放 (Drag & Drop)：從預覽區拖拽圖片到表格的格子中
  • 自動填充（正序）：點擊 "Auto-fill (ascending)" 按順序填充格子（1, 2, 3...）
  • 自動填充（倒序）：點擊 "Auto-fill (descending)" 反向填充格子

步驟 4：合併圖片

當所有圖片都放置到表格後：

  • 點擊 "Merge Table Images" 按鈕
  • 合併後的圖片會在上方顯示為畫布
  • 您可以調整表格配置並重新合併

步驟 5：下載結果

合併完成後：

  • 點擊 "下載合併圖片" (Download Merged Image) 按鈕
  • 選擇保存位置並完成下載
💡 提示 (Tips)：
  • 所有操作都在您的瀏覽器本地完成，您的圖片不會上傳到任何服務器
  • 點擊 "清空表格" (Clear table) 可以清除所有內容並重新開始
  • 您可以隨時調整行數、列數和間距來獲得不同的合併效果
🔒 隱私保護 (Privacy)：

此工具完全在本地運行，所有圖片處理都在您的設備上完成。我們不會存儲或上傳您的任何圖片。
